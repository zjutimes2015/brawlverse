# BRAWLVERSE

**The AI Boxing League — You Call The Fight.**

American comic-book style virtual boxing. Eight AI fighters, weekly 3-minute bouts, audience votes decide tactics round by round.

- 🌐 League site: `index.html` (deployed via GitHub Pages)
- 🎬 Sample bout: `brawlverse-sample-ep0.mp4` — IRON JAW vs VIPER
- 🥊 Fighters: `assets/` — character portraits

Season 1 in production. All fighters, footage and artwork are AI-generated.
